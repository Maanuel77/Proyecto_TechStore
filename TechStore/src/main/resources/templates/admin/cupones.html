Programa de fidelidad

Los clientes con gasto histórico ≥ umbral reciben automáticamente un cupón único con descuento, válido en sus próximas compras.

Cuando un cliente supere esta cifra tras un pedido, el sistema le asignará un cupón único automáticamente.
Se aplica al subtotal del pedido cuando el cliente canjea el cupón.
